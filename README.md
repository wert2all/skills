# Skills

This repository contains [skills.sh](https://skills.sh) skills for my development process.

## Origin

Forked and adapted from [Matt Pocock's skills](https://github.com/mattpocock/skills) — modified to fit my workflow and project needs.

## Skills

| Skill | Description |
|---|---|
| **wayfinder** | Plan and navigate large, foggy work chunks via investigation tickets |
| **grilling** | Critically question a spec or design to find gaps |
| **grill-with-docs** | Grill an idea while grounding it in project docs |
| **domain-modeling** | Model a domain from requirements |
| **to-spec** | Convert loose requirements into a structured spec |
| **to-tickets** | Break a spec into actionable tickets |
| **code-review** | Review changes against standards and spec |

## Structure

Each skill lives in `skills/<name>/SKILL.md` following the [skills.sh schema](https://skills.sh/schemas/skills.sh.schema.json). The `skills.sh.json` defines groupings for the pi agent.
